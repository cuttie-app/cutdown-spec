# 0.2.0

Baseline. The first published spec; nothing precedes it, so no entry is
classifiable as breaking or additive.

Established: the document model, block and inline segment sets, universal
attributes, the parsing algorithm, precedence and whitespace rules, the special
character reference, and the AST node reference. Golden YAML fixtures became the
conformance corpus.

Extensions were cut from the spec in this line; `Mention` moved to the
extensions list rather than the core segment set.

## [ADDITIVE] BIDI conformance

Rules for bidirectional text added to input interpretation.
