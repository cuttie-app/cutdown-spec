# 0.11.0

## [BREAKING] `type` renamed to `_type`

```
Before:  { type: "Paragraph", … }
After:   { _type: "Paragraph", … }
```

Property names beginning with `_` are reserved for structural properties.

## [BREAKING] No `null` in the AST except `Page.meta`

| Property | Was | Now |
|---|---|---|
| `reflection` | `Reflection[] \| null` | `Reflection[]`, `[]` when absent |
| `caption` | `Inline[] \| null` | `Inline[]`, `[]` when absent |
| `List.start` | `number \| null` | `number`, `1` unless numbered |

## [BREAKING] `ImageBlock` removed

```
Before:  ![a](b)  →  ImageBlock
After:   ![a](b)  →  Paragraph([ImageInline])
```

## [BREAKING] `FileRef` renamed to `FileBlock`; `FileRefGroup` renamed to `FileGroup`

```
Before:  /a.png  →  FileRefGroup { group: "image", caption } > FileRef { path, query, fragment, caption, reflection }
After:   /a.png  →  FileGroup > FileBlock { src: PathResourceLocator, caption }
```

## [BREAKING] `FileGroup` wraps every run of file lines

Consecutive file lines form one group whatever their extensions; a blank line splits it; a single file line forms a group of one. `group`, the known-group extension table, and the group caption are removed.

## [BREAKING] File captions bind to the `FileBlock`

A `^ ` line binds to the file above it and no longer closes the group.

## [BREAKING] A lone `/` is a `FileBlock`

## [BREAKING] `##` comments attach to the node that owns the line

```
Before:  - a ## note  →  List { reflection: [note] }
After:   - a ## note  →  ListItem { reflection: [note] }
```

`List`, `Table`, and `FileGroup` lose `reflection`; `ListItem`, `TaskItem`, `Row`, and `FileBlock` gain it. A comment on a header separator goes to the row above it.

## [BREAKING] A `##` line directly after an item, row, or file keeps the run open

```
Before:  - a / ## c / - b  →  List, List
After:   - a / ## c / - b  →  List(a { reflection: [c] }, b)
```

## [BREAKING] A `##` line after a blank line is an empty `Paragraph`

```
Before:  Para / (blank) / ## c  →  Paragraph(Para) { reflection: [c] }
After:   Para / (blank) / ## c  →  Paragraph(Para), Paragraph { children: [], reflection: [c] }
```

## [BREAKING] A header separator with no row above it inserts an empty `Header` row

## [BREAKING] A lone `|` is a `Table` with one empty `Row`

A row with no cells does not fix the column count.

## [BREAKING] Canonical form row 7 replaced

The separator-only table is no longer an alias of `|`; row 7 now omits an empty `Header` row before a header separator.

## [BREAKING] `PathResourceLocator` replaces raw path strings

`FileBlock`, `InjectBlock`, `ImageInline`, and page `Link` carry `raw` plus a `{ path, query, fragment }` locator in `src` or `path`, `null` when the path is invalid. Paths admit spaces and any Unicode; brackets nest; `query` is a list of `{ key, value }` pairs.

```
Before:  [x][a/b]  →  Link { target: "a/b" }
After:   [x](a/b)  →  Link { raw: "a/b", path: { path: "a/b", query: [], fragment: "" } }
```

## [BREAKING] `null` marks a missing path

An invalid path, and the path of a non-page `Link`, is `null`; `Page.meta` stays the other `null`.

## [BREAKING] `![alt](https://…)` is an `EmbedImageInline`

```
Before:  ![a](https://x/a.png)  →  ImageInline { src: "https://x/a.png" }
After:   ![a](https://x/a.png)  →  Paragraph([EmbedImageInline { url: "https://x/a.png" }])
```

## [BREAKING] One link form: `[text](target)`

The target's first characters choose the kind. `[text][target]` is no longer a link.

| Kind | Before | After |
|---|---|---|
| external | `[x](https://a.b)` | `[x](https://a.b)`, `[x](mailto:a@b.c)` — any URI scheme |
| page | `[x][guide/intro]` | `[x](guide/intro)` |
| id | — | `[x](#install)` |
| ref | `[x][^n]` | `[x](^n)` |
| tag | `[x][#a/b]` | `[x](~a/b)` |
| cite | `[x][@k]` | `[x](@k)` |

`kind` gains `"id"`. A ref link names only a `RefDefinition` and is a footnote reference; an element id is reached with `#id`. A page-link fragment names any segment with that id. `[](target)` shows the target itself. `[text][target]` is literal text with warning CDN-0036.

## [BREAKING] The parser appends `.cutdown` to page paths

```
Before:  [x](guide/intro)  →  path: { path: "guide/intro" }      (the consumer appended .cutdown)
After:   [x](guide/intro)  →  path: { path: "guide/intro.cutdown" }
```

## [BREAKING] `[text]()` is a wiki link

```
Before:  [Getting started]()  →  Link { kind: "external", href: "" }
After:   [Getting started]()  →  Link { kind: "page", raw: "", path: { path: "/Getting started.cutdown" } }
```

The path is the text as a reader sees it, from the root; only `/` splits folders. `[]()` names nothing: `path: null` and CDN-0032.

## [BREAKING] `PATH_LITERAL` removed

Page paths use `PathResourceLocator`; tag levels use the new `TAG_LITERAL`, which admits spaces and non-ASCII letters.

## [BREAKING] A `https://` line is an `EmbedBlock`

```
Before:  https://youtu.be/x  →  Paragraph
After:   https://youtu.be/x  →  EmbedBlock { url }
```

## [BREAKING] A `.cutdown` or folder path is an `InjectBlock`

```
Before:  /intro.cutdown  →  FileRef
After:   /intro.cutdown  →  InjectBlock { src, children: [] }
```

## [BREAKING] `.class` and `class=` merge

```
Before:  {.a class="b"}  →  class: ["a"] + CDN-0021
After:   {.a class="b"}  →  class: ["a", "b"]
```

CDN-0021 is deprecated and no longer emitted.

## [BREAKING] `key={…}` and `key=[…]` hold parsed JSON

```
Before:  {d={"a":1}}  →  literal text
After:   {d={"a":1}}  →  { key: "d", value: { a: 1 } }
```

## [BREAKING] Ordered markers take 1–5 digits; `0` starts at `1`

```
Before:  123456. x  →  List { start: 123456 }
After:   123456. x  →  Paragraph

Before:  0. x       →  List { start: 0 }
After:   0. x       →  List { start: 1 }
```

## [BREAKING] Header separator cells need three symbols, marks included

```
Before:  |:-:|  →  content row
After:   |:-:|  →  header separator, "center"
```

## [BREAKING] `MathInline` keeps its whitespace

## [BREAKING] Synthetic `Fragment` removed

`InjectBlock` covers consumer-placed content.

## [ADDITIVE] §17 Injection

Defines what a consumer places in `InjectBlock.children`: the injected Pages' blocks with `meta` dropped, a Section boundary at the block's edge, identifiers local to each document, `#id` and `?key=value` meaning, and folder order.

## [ADDITIVE] Interpolation tokens in string properties

`{{key}}` in paths, `href`, `url`, and attribute values stays verbatim for the consumer, and so do the escapes `\\` and `\{{`; the consumer resolves all three in one pass.

## [ADDITIVE] CDN-0032 — Invalid path

An `http://` value is read as a path; the warning hints at `https://`.

## [ADDITIVE] CDN-0033 — Invalid link target

An id, ref, tag, or cite target is empty or holds a character its kind does not admit.

## [ADDITIVE] CDN-0036 — Unsupported link form `[text][target]`

## [ADDITIVE] Ids admit any letters

An id is any Unicode except whitespace, `#`, `)`, `}`, and control characters, for `{#id}`, `id=`, and `[x](#id)` alike: `{#Установка}` is valid.

## [ADDITIVE] CDN-0037 — Invalid id

An id value outside that set is kept as written and warned about.

## [ADDITIVE] CDN-0034 — Class limit exceeded

A `{…}` group keeps at most 32 classes.

## [ADDITIVE] CDN-0035 — Value exceeds limit of 2048 chars

A path, `EmbedBlock.url`, or `Link.href` over 2048 characters is kept in full and warned about.

## [ADDITIVE] Canonical form rows for padding, classes, and the final newline

Containers and list items are padded 2 spaces per level with no tabs; classes are written as `.name` tokens; a document ends with one line terminator; a leading `0.` is written `1.`.
