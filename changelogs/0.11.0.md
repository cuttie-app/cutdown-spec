# 0.11.0

## [BREAKING] `type` renamed to `_type`

```
Before:  { type: "Paragraph", … }
After:   { _type: "Paragraph", … }
```

Property names beginning with `_` are reserved for structural properties.

## [BREAKING] No `null` in the AST except `Page.meta`

| Property | Was | Now |
|---|---|---|
| `reflection` | `Reflection[] \| null` | `reflections: LineReflection[]`, `[]` when absent |
| `caption` | `Inline[] \| null` | `Inline[]`, `[]` when absent |
| `List.start` | `number \| null` | `number`, `1` unless numbered |

## [BREAKING] `ImageBlock` removed

```
Before:  ![a](b)  →  ImageBlock
After:   ![a](b)  →  Paragraph([ImageInline])
```

## [BREAKING] `FileRef` renamed to `FileBlock`; `FileRefGroup` renamed to `FileGroup`

```
Before:  /a.png  →  FileRefGroup { group: "image", caption } > FileRef { path, query, fragment, caption, reflection }
After:   /a.png  →  FileGroup > FileBlock { src: PathResourceLocator, caption }
```

## [BREAKING] `FileGroup` wraps every run of file lines

Consecutive file lines form one group whatever their extensions; a blank line splits it; a single file line forms a group of one. `group`, the known-group extension table, and the group caption are removed.

## [BREAKING] File captions bind to the `FileBlock`

A `^ ` line binds to the file above it and no longer closes the group.

## [BREAKING] A lone `/` is a `FileBlock`

## [BREAKING] `##` comments attach to the node that owns the line

```
Before:  - a ## note  →  List { reflection: [note] }
After:   - a ## note  →  ListItem { reflections: [note] }
```

`List`, `Table`, and `FileGroup` lose `reflection`; `ListItem`, `TaskItem`, `Row`, and `FileBlock` gain `reflections`. A comment on a header separator goes to the row above it.

## [BREAKING] A `##` line directly after an item, row, or file keeps the run open

```
Before:  - a / ## c / - b  →  List, List
After:   - a / ## c / - b  →  List(a { reflections: [c] }, b)
```

## [BREAKING] A `##` line after a blank line goes to the Page

```
Before:  Para / (blank) / ## c  →  Paragraph(Para) { reflection: [c] }
After:   Para / (blank) / ## c  →  Page { reflections: [{ text: "c", before: [1] }], children: [Paragraph(Para)] }
```

So does a `##` line with no block before it in its scope, or directly after a `###` closer.

## [BREAKING] `CommentBlock` node removed; its text goes to `Page.reflections`

```
Before:  ### / note / ###  →  CommentBlock { text: "note\n" }
After:   ### / note / ###  →  Page { reflections: [{ text: "note", before: [0] }] }
```

A CommentBlock at any depth, inside a list item or a named block included, goes to its Page. Its text has no trailing newline. `before` is the child-index path of the block the comment stands before, so a writer can put it back; a body that becomes one paragraph once the comment is gone is held as inline content.

## [BREAKING] `reflection` renamed to `reflections`; `Reflection` split in two

```
Before:  reflection: Reflection[]
After:   reflections: LineReflection[]          (on blocks)
         reflections: SegmentReflection[]       (on Page; adds before: number[])
```

## [BREAKING] A header separator with no row above it inserts an empty `Header` row

## [BREAKING] A lone `|` is a `Table` with one empty `Row`

A row with no cells does not fix the column count.

## [BREAKING] Canonical form row 6 replaced

The separator-only table is no longer an alias of `|`; row 6 now omits an empty `Header` row before a header separator.

## [BREAKING] `PathResourceLocator` replaces raw path strings

`FileBlock`, `InjectBlock`, `ImageInline`, and page `Link` carry `raw` plus a `{ path, query, fragment }` locator in `src` or `path`, `null` when the path is invalid. Paths admit spaces and any Unicode; brackets nest; `query` is a list of `{ key, value }` pairs.

```
Before:  [x][a/b]  →  Link { target: "a/b" }
After:   [x](a/b)  →  Link { raw: "a/b", path: { path: "/a/b.cutdown", query: [], fragment: "" } }
```

## [BREAKING] Paths are read from the project root

```
Before:  ![x](images/a.png)  →  path: "images/a.png"   (relative to the document)
After:   ![x](images/a.png)  →  path: "/images/a.png"

Before:  [x](../intro)  →  path: "../intro"
After:   [x](../intro)  →  path: null + CDN-0032
```

## [BREAKING] The parser normalizes `path`

```
Before:  /a/./b/../c.png  →  path: "/a/./b/../c.png"
After:   /a/./b/../c.png  →  path: "/a/c.png"

Before:  /a//b.png  →  src: null + CDN-0032
After:   /a//b.png  →  path: "/a/b.png"
```

`path` is converted to NFC; `raw`, `query`, and `fragment` stay as written. Block type and validity read the normalized path: `/chapters/.` is a folder `InjectBlock`, and `/./` is a `FileBlock`.

## [BREAKING] Ids and page-link fragments are converted to NFC

## [BREAKING] A tag level may not be `.` or `..`

## [BREAKING] `null` marks a missing path

An invalid path, and the path of a non-page `Link`, is `null`; `Page.meta` stays the other `null`.

## [BREAKING] An image source must name a file

```
Before:  ![x]()  ![x](~t)  ![x](tel:1)  →  ImageInline { src: { path: … } }
After:   ![x]()  ![x](~t)  ![x](tel:1)  →  ImageInline { src: null } + CDN-0032
```

An empty path, a leading link sigil (`#`, `^`, `~`, `@`), and any scheme but `https://` are invalid in an image. A link is a pointer and takes any target; an image is fetched and placed, so it takes only a file.

## [BREAKING] `/#` and `/?…` are `FileBlock`s

A path of `/` alone never injects the root folder.

## [BREAKING] `![alt](https://…)` is an `EmbedImageInline`

```
Before:  ![a](https://x/a.png)  →  ImageInline { src: "https://x/a.png" }
After:   ![a](https://x/a.png)  →  Paragraph([EmbedImageInline { url: "https://x/a.png" }])
```

## [BREAKING] One link form: `[text](target)`

The target's first characters choose the kind. `[text][target]` is no longer a link.

| Kind | Before | After |
|---|---|---|
| external | `[x](https://a.b)` | `[x](https://a.b)`, `[x](mailto:a@b.c)` — any URI scheme |
| page | `[x][guide/intro]` | `[x](guide/intro)` |
| id | — | `[x](#install)` |
| ref | `[x][^n]` | `[x](^n)` |
| tag | `[x][#a/b]` | `[x](~a/b)` |
| cite | `[x][@k]` | `[x](@k)` |

`kind` gains `"id"`. A ref link names only a `RefDefinition` and is a footnote reference; an element id is reached with `#id`. A page-link fragment names any segment with that id. `[](target)` shows the target itself. `[text][target]` is literal text with warning CDN-0036.

## [BREAKING] The parser appends `.cutdown` to page paths

```
Before:  [x](guide/intro)  →  path: { path: "guide/intro" }      (the consumer appended .cutdown)
After:   [x](guide/intro)  →  path: { path: "/guide/intro.cutdown" }
```

## [BREAKING] `[text]()` is a wiki link

```
Before:  [Getting started]()  →  Link { kind: "external", href: "" }
After:   [Getting started]()  →  Link { kind: "page", raw: "", path: { path: "/Getting started.cutdown" } }
```

The path is the text as a reader sees it, from the root; `/` splits folders and `.` and `..` are normalized. `[]()` names nothing: `path: null` and CDN-0032.

## [BREAKING] `PATH_LITERAL` removed

Page paths use `PathResourceLocator`; tag levels use the new `TAG_LITERAL`, which admits spaces and non-ASCII letters.

## [BREAKING] A `https://` line is an `EmbedBlock`

```
Before:  https://youtu.be/x  →  Paragraph
After:   https://youtu.be/x  →  EmbedBlock { url }
```

After:   /intro.cutdown  →  InjectBlock { src, children: [] }
```

## [BREAKING] `.class` and `class=` merge

## [BREAKING] One rule for every fence

A line beginning with three or more fence symbols opens the fence, and the next such line closes it. Three symbols are consumed; the rest of the line is dropped with CDN-0016, except a language, format, or name word, `{attrs}`, or a `## comment` where the construct keeps them.

```
Before:  ### note        →  ?
After:   ### note        →  CommentBlock opener + CDN-0016

Before:  ``` done        →  body content of the open CodeBlock
After:   ``` done        →  closes the CodeBlock + CDN-0016

Before:  ::: {.alert}    →  Paragraph + CDN-0013
After:   ::: {.alert}    →  NamedBlock { name: "" } + CDN-0013
```

An unknown CodeBlock language gives `"text"` and CDN-0038; an unknown Meta format gives `yaml` and CDN-0039.

## [BREAKING] Escapes, `CodeInline`, and `MathInline` take precedence over `##`

`\##`, `$$x ## y$$`, and a closed ``` ``a ## b`` ``` hold no comment; behind an opener that never closes, `##` is a comment.

## [BREAKING] No `error` diagnostic level

`level` is `warning` or `info`. A tool may still fail its own build on a warning; the parse result does not change.

## [BREAKING] Canonical form is byte-identical

Writers no longer wrap lines, separate blocks by exactly one blank line, pad table cells with one space, and write three-symbol separator cells. New aliases: `#x` for `id=`, bare `key=v`, bare `~~~` and ```` ``` ```` for the defaults, LF, one space for interior runs, NFC ids. The unchecked-task row is removed, so later rows move up by one.

## [BREAKING] A line marker needs whitespace or a line end after it

```

## [BREAKING] Trailing whitespace is dropped; leading whitespace marks the word boundary

```

After:   "a \nb"  → "ab"       "a\n  b"  → "a b"

## [BREAKING] A container whose body is one paragraph holds its inline content
