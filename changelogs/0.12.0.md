# 0.12.0

## [BREAKING] A span kind never repeats, even inside link text, `alt`, or Mark content

```
Before:  **a [b **c** d](u) e**  →  Strong(a, Link(b, Strong(c), d), e)
After:   **a [b **c** d](u) e**  →  Strong(a [b), Text(c), Strong(d](u) e) + CDN-0014
```

An open span closes at its first closer wherever it stands; link text, `alt`, and Mark content do not reset it.

## [BREAKING] Mark content is transparent to spans and links

```
Before:  **a ::m b** c:: d**  →  Strong(a, Mark(b** c), d)
After:   **a ::m b** c:: d**  →  Strong(a ::m b), Text( c:: d**) + CDN-0014
```

Marks still match each other by counting; against every other inline they follow source order. CDN-0014 also fires when a Mark opener is crossed.

## [BREAKING] Inline depth is bounded at 16

```
Before:  inline depth 28
After:   inline depth 16
```

## [BREAKING] `{{}}` emits CDN-0015

## [BREAKING] A CommentBlock fence ends a paragraph or heading run

```
Before:  text / ### / note / ###  →  Paragraph(text###note###)
After:   text / ### / note / ###  →  Paragraph(text) + SegmentReflection(note)
```
